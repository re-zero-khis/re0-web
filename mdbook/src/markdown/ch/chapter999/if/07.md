# 『鬼的幸福』

「怎、怎么会……这，骗人的吧……！？」

昴站在街上抱住脑袋，惊叫出声。

他的眼中满是动摇，神色慌乱，视线牢牢钉在市场两侧的一家露天摊位上。褐色皮肤的店员被他夸张的反应吓得瞪圆了眼睛。

然而，昴已被惊讶占据了心神，根本没留意店员的反应。

他嘴唇颤抖，连额头沁出的汗珠也忘了擦，只咽下一口格外苦涩的唾沫。这时，见他停下脚步——

「喂，你怎么突然不走了？再不赶紧回去，要挨骂的吧。」

走在前面的同行者撅着嘴折了回来。

少年双手交叠在脑后，锐利的眼神毫不掩饰不满。不过昴知道，那几乎能把人瞪死的凶狠目光是天生的，与他此刻心情好不好无关。

毕竟，若论因为眼神和长相遭受无端中伤，昴自己就是个过来人。

「坚强地活下去啊……」

「你干吗突然可怜起我来了！啊，算了！我不想听！我知道听了只会更郁闷！别说！都叫你别说了！」

「你这么起劲地给我铺垫，我都忍不住来劲了。说真的，你可真会煽动我啊。天赋异禀，莫非你有加护？」

「这种加护谁稀罕啊！老天爷有空发这种东西，还不如给我点有用的！」

被昴的话气得唾沫横飞，三白眼的蓝发少年仰头望天，长吁短叹。昴对他夸张的反应连连点头，随后重新转向看得发愣的摊主。

然后，

「这个，多少钱？」

「啊？」

昴清了清嗓子，指向摊位上摆着的『那东西』，

「我要这个。给我先来三袋。」

「哎，啊～！谢谢惠顾！」

「等！等一下！你突然买什么啊……买多余的东西回去，可就不只是挨骂了，她会直接动手的吧！」

摊主明白昴的意思，刚爽快地应下，少年便脸色大变地扑了过来。他拉住昴身后的衣摆，催他再考虑一下。昴抓住他的手，蹲下来与他平视，


「放心，我不会动买东西的钱。这是我的私房钱，一点点攒下来的零花钱。你也知道，我平时没什么地方要花零用钱吧。」

「啊啊，嗯......不喝酒、不抽烟也不赌博，除此之外的使用方法......都是花到女人身上呢」

「你是故意说得让人误会吧？这么坏心眼，又这么别扭，到底像谁啊，我还真想知道。」

「大体上没错，是遗传基因啊。令人悲伤。」

昴叹着气摇了摇头，少年却竖起左手中指，理直气壮地如此宣告。昴抓住那根中指一扳，少年刚低声叫了个「啊」，便被指关节的疼痛逼得惨叫起来。

两人闹腾的工夫，店员已麻利地把货品装进袋子，挂起招徕生意的笑容，

「关系真好啊，老爷。和那边的小子是亲子吗？」

「喂喂，就凭这么点线索竟然能看出来……做生意的眼力还真不能小看啊！你说是吧，利格尔？」

被关节技压倒的少年——利格尔不服气地大叫。昴听了，只若无其事地应道：「嘛，倒也是。」

这时，货品也装好了。店员将三个小袋推过来，昴从怀中掏出一只装着零花钱、权当钱包的袋子，

「那，银币三枚足够了——老哥，找零就不用了，收好。」

「世界要是变得能让人这样想，我觉得是件好事。我原本就喜欢鬼，现在老婆是鬼，更是幸福得不得了。也许这个习俗的寓意，已经变成了无论好事坏事，都好好品味着活下去吧。」

世间总在变迁，有好也有坏，节分的意义、看待鬼的方式也会随之改变。

在昴的故乡，把鬼塑造成萌角色都只是稀松平常的小事。昴也充分继承了这种民族性，所以毫无抵触。老婆实在太可爱了。

「鬼啊～，来我家～！福也～，来我家～！」

「什么啊？」

「鬼进来，福也进来。就是两样都迎进来的意思。对我来说，鬼和福都是幸福的象征。贪心一点，两个都要……怎么样？」

缩起肩膀看向昴，利格尔想说什么似得嘴巴一张一合，结果什么也没说松开肩膀放弃了。

看到儿子的反应，昴笑了。一直坐在他膝上任他摆布的雷姆，也「呵呵」地笑出声，

「昴的那种思考方式，雷姆最喜欢了。——来做吧，节分」

「哦，终于愿意了？那就趁你还没改变主意赶紧开始吧。节分也可以像我带来的那些游戏一样，推广出去。」

抱起抬起头的雷姆，站起来的昴，只跟雷姆交换了下视线。昴点点头，

「你看，推广『冰鬼』游戏的时候我就有这种感觉，卡拉拉基总让我觉得很容易融入。」

「这里时不时就会有些地方，跟我的故乡重合。」

「时常说起呢。有那种感觉吗？」

「我以前开玩笑提过，他们不是在做尊重民意、通过投票选出总理大臣……类似的事情吗？也有接近愚人节、圣诞节的活动。」

「也许是因为多些活动和节日，就能为做生意创造更多热闹的机会……？」

「也有这些的关系，但感觉不只是这样......嘛，现在就算了」

确实是不错的居住国。跟雷姆两人移居过来已经九年了。

若非卡拉拉基宽厚而富有人情味的风气，两人恐怕也没法这么顺利地走到今天。只是关西话——不，是卡拉拉基方言，昴至今仍不太习惯。

「喂，豆子拿来了。要开始就赶快吧」

「哦，不愧是我儿子，真体贴。嘴上说着不要，其实心里早就兴奋得藏不住了吧？利格尔，小孩子——！」

「总比让老婆操心品行、操心得比儿子还多的老爸强吧！」

从起居室拿来豆子的利格尔，粗暴地分给昴和雷姆一人一袋，自己也留下了一袋。

昴向面面相觑，用眼神询问该怎么办才好的两人点了下头，把手插进袋子并抓起一把豆子。

「很简单。像刚才说的，喊『鬼往外，福进来！』就行。啊不对，这次用鬼和福都迎进来的版本，就这么办。」

「那个，豆子……朝鬼扔过去就行了吗？」

「妈妈，你这时候看着我，眼神有点吓人啊！」

「嗯，是这样，但可别真用力。做做样子就好，轻一点。」

确认完所有流程，现在起节分——开始了。

相互面对面，手里拿着豆子，

「喂！鬼啊～，来我家～！福也～，来我家～！」

「嗯……鬼、鬼啊～，来我家～！福也～，来我家～！」

「鬼啊～，啊，丝碧卡别哭！别哭了！啊，等一下，先别扔豆子！」

咕噜咕噜地，同刚才一样围着屋子转着圈，开始播撒豆子。

昴兴致勃勃，雷姆起初还有点害羞，后来也渐渐忘了羞意，笑着撒起豆子。利格尔却不知为何主动给自己加了难度，一边抱着丝碧卡，一边手忙脚乱地跟上。

「喂！鬼啊～，来我家～！福也～，来我家～！」

鬼是亲人，幸福在家中，这就是菜月家的节分情形。

得到身为鬼的老婆，彼此间得到有鬼的血的孩子，就这样享受着节分的新形式。——

这是，多么幸福的事啊。

豆子在屋里，走廊里，家的各处飞散。

一想到事后还得打扫，难免有些头疼——但为了担心收拾，就不去享受眼前这一刻，那才真是犯傻。

笑着，笑着，一边笑着，一边抛洒豆子。

和可爱的鬼们一起，幸福感填满了胸膛，播撒豆子吧。

将鬼与幸福一起迎进家门，放声大笑，尽情相爱吧。

「昴」

忽然，雷姆的笑容出现在昴的旁边。

昴低头看去，雷姆依偎过来，双颊泛红，笑盈盈地望着他，

「今天也好，今后也好，你都会将雷姆和幸福一起拥在怀里吗？」

她说着扑进昴的怀里。昴回抱住她，

「——不是说过了吗？和鬼一起创造未来，是我很久很久以来的梦想啊。」

此刻的幸福，还有今后长长久久的幸福，都真切地拥在胸前。

昴将无尽的爱意融进声音，轻轻地如此呢喃。
