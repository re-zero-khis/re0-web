# 『突破口』

------

——帝都鲁普加纳的包围战，从双方毫不保留的激战开始。

现在佛拉基亚的反叛军对国家抱有不满，而正规军则力图维护这个国家。本来，艾米莉娅等人没有必要参加这场堪称全面战争的战斗。

起初，艾米莉娅一行之所以进入帝国，是为了寻找失踪的人。

当然，他们潜入佛拉基亚，途中结识了许多人，与他们建立了感情和义理。

无关王国或帝国的国界之分，途中确实有让他们希望对方幸福、想要伸手相助的人。这是一行人都承认的。

然而，即使对这群毫无疑问是好心人的艾米莉娅一行来说，他们也有优先次序。

若顾此失彼，忘了最初的目的，便是本末倒置。队伍中既有下意识就想救人的良心（艾米莉娅、加菲尔），也有能出言劝阻的判断力（奥托、佩特拉）。

他们参加了被飞龙袭击的城郭都市的战斗，也是因为他们一直在追踪着寻找那个城市的伙伴的信息。

既然这个线索没有结果，那么按理说，艾米莉娅等人参加叛军攻击帝都的理由就根本不存在。

实际上，在听到帝国日益恶化的形势时，艾米莉娅一行的决心很坚定，他们对目标的关注仅受到了最小程度的干扰。

然而——，

「——既然掳走那姑娘的是『飞龙将』，她便应在龙人玛德琳・艾沙尔的住处，或是那家伙饲主的宅邸」

站在城郭都市市政厅最高层房间前展开地图的埃布尔，他摸了摸遮住脸的鬼面，回答了艾米莉娅的问题。

听见埃布尔的回答，艾米莉娅喃喃道：「玛德琳的饲主……」

—— 时间回溯到帝都鲁普加纳包围战的几天前。

昴去了魔都，本应返回古拉尔，可艾米莉娅等人与他会合的打算落了空，连已经苏醒的雷姆也错过了。他们正为接下来的方针犯难。

在魔都卡欧斯弗莱姆崩溃后，他们不知道昴的下落，却知道绑架雷姆的对方的身份，他们纠结于应该优先寻找哪个人。

艾米莉娅渴望得到判断依据，而埃布尔告诉她的就是开头的话。

「此话不能让那暴躁的龙人听见，不过，她是宰相贝尔斯提兹・冯达尔福举荐的一将。有事自会回到那人身边」

「——」

「怎么了？有什么疑虑吗？」

「不，不是那个……只是觉得用『饲主』这个词说法，很不妥当。」

虽然艾米莉娅与玛德琳的交流很少，甚至可以说两人关系非常紧张，但她认为埃布尔现在的说法，如果让玛德琳听到，肯定会让她非常生气。

面对艾米莉娅的指正，埃布尔默不作声，眼神从面具的深处变得狭长。希望他能回想起自己的话，并对其表示反省。

无论如何，对于艾米莉娅他们所不了解的帝国情况，埃布尔的见解是非常有帮助的。

帝国各地的反叛氛围日益高涨，甚至连天空和空气的干燥程度都变得糟糕，这种感觉让希望事情尽可能发展顺利的艾米莉娅也不禁感到不安。

与要找的人重逢的机会屡屡落空。在帝国，他们的时机总是差了一步。

「但是，如果玛德琳回到那个贝尔斯提兹的身边，雷姆也会……」

「雷姆在的话，哥哥也一定在！」

艾米莉娅顺着线索思索，趴在作战桌旁的米迪娅姆也连忙接话。

米迪娅姆竭力伸展着她的小身体以吸引注意力，与艾米莉娅的目光相遇，艾米莉娅的嘴角微微上扬。米迪娅姆的亲兄长也是被玛德琳带走的人之一，与雷姆在一起。

尽管肯定非常担心和不安，米迪娅姆却一点也没有表现出软弱的样子。

艾米莉娅觉得自己也应该向她的坚强学习。

「宰相……贝尔斯提兹・冯达尔福阁下，是一个非常优秀且有能力的人，被称为帝国的支柱对吧？」

艾米莉娅正为米迪娅姆的坚强动容，身旁的佩特拉插入了这番话。

佩特拉不放心让艾米莉娅独自前来，便陪在了她身边。见她指尖抵着嘴唇低语，艾米莉娅歪头问：「是这样吗？」

「帝国的支柱这个评价很高，但这不是指皇帝吗？」

「当然，帝国长期和平都是因为皇帝阁下的力量。但是，皇帝阁下的力量，也包括善于使用优秀部下的能力。」

「啊，是这样啊。即使皇帝非常强大，非常聪明，也不可能一个人完成所有事情。」

正在努力的艾米莉娅并不认为自己与佛拉基亚皇帝处于同一个层次。但是，她迟早需要达到同样的地位，而且她应该为此而努力。

然而，无论艾米莉娅努力到什么程度，她肯定会一直借助其他人的力量。

佛拉基亚的皇帝也应该是这样。

然而，在令艾米莉娅和米迪娅姆敬佩的同时，埃布尔似乎有着完全不同的看法。他透过鬼面看着佩特拉，眼神变得锐利。

「故意让我听这个理所当然的道理是为了什么？你认为我有空倾听一个小孩子的话吗？这时间可是宝贵的。」

「抱歉，是我绕弯子了。其实只是想问——既然是皇帝阁下倚重的心腹，宰相先生的宅邸应该就在帝都吧？」

「……」

佩特拉毫不畏惧埃布尔的锐利眼神，而埃布尔对她的质问保持沉默。

埃布尔可怕的目光，本应让人感觉仿佛被刀锋所指，然而佩特拉却丝毫未受影响。这足以证明她的心灵有多强大。

那份坚强，甚至让同为伙伴的艾米莉娅也想自豪地挺起胸膛。

「答案是肯定的。既然如此，被玛德琳・艾沙尔掳走的两人……雷姆与弗洛普・奥克尼尔，想必也在帝都贝尔斯提兹的宅邸」

埃布尔似乎被佩特拉的目光压倒，低声回答道。艾米莉娅听到这个回答，想要称赞佩特拉真是了不起。

然而，佩特拉的表情却没有高兴起来，反而明显地叹了口气，

「……这感觉像是被安排好的，一点都不有趣。」

「诶？这是什么意思？」

艾米莉娅不解地眨眼。听见她的疑问，佩特拉仍一脸不快，压低声音答道。

「我们和这个帝国发生的问题并无关系。我知道这会演变成一场非常大的战斗，虽然很担心米迪娅姆和乌塔卡塔这样的孩子们，但是……」

「――。嗯，没关系的。我明白你想说的。我们来这里是为了寻找昴和雷姆。」

艾米莉娅温柔地选择了词语，抢在似乎难以启齿的佩特拉之前说出了话。

艾米莉娅当然能理解佩特拉的不安和顾虑。如果条件允许，艾米莉娅也想和埃布尔他们一起合作，为所有相识的人提供帮助。

但是，如果只关注眼前的问题，她们就无法达到寻找昴等人的真正目的——

「咦？」

正考虑到这里时，艾米莉娅突然感到有些困惑。

正如她向佩特拉解释的那样，她们的目标是安全地带回昴和雷姆。所以即使很痛苦，她们也必须无视佛拉基亚发生的战斗。

虽然她是这么想的。

「但是现在，雷姆可能在帝都。那么……」

「――我们也必须去帝都」

艾米莉娅的疑惑冰消瓦解，终于与早已想通的佩特拉对上目光。

佩特拉早已注意到这个事实，所以她一直都是一副苦涩的表情。为了证实艾米莉娅的惊讶，佩特拉瞪了埃布尔一眼。

接着――，

「太卑鄙了。在我们提出来之前，你一直保持沉默。」

「稍加梳理，自会得出同一个结论。将自己的迟钝置之不理，却骂我卑劣，未免太过傲慢」

「那么请告诉我们。您说『飞龙将』玛德琳小姐会回去的地方，除了帝都宰相家，还有另一处吧。可您一直只谈帝都，刻意不让艾米莉注意到另一种可能」

「――――」

「在我家乡，利用别人的无知来占便宜被称为无耻行为。」

佩特拉目光尖锐地责问埃布尔。听她这么一说，艾米莉娅才意识到，自己竟轻易被遮掩过去，漏掉了重要的信息，不由垂下眉梢。

在埃布尔身边，正在仔细审视地图的米迪娅姆也瞥了一眼埃布尔，「埃布尔先生……」，她用提醒的语气看着他。

艾米莉娅深深反省，同时也十分理解佩特拉生气的理由。

姑且不论隐瞒信息之事，先前那番道理确实如埃布尔所说，只要她仔细思考便能察觉。可即便如此，他直接告诉她又有何妨。

当然，艾米莉娅并不打算在所有问题上都依赖他人。

「埃布尔刚才不也说时间紧迫吗？我们也是一样啊，别故意为难人」

「这说明你的傲慢。为什么我要专门为你讲解事情的道理呢？」

「——？想借我们的力量，就该好好说『拜托了』才对吧」

「——。说不到一处的女人」

埃布尔双手交叠，长长地呼出了一口气。

艾米莉娅却歪头道「是吗」，心里有着不同的看法。不是说不到一处，而是埃布尔不愿好好与他们沟通。

「难道不是吗？接下来要打佛拉基亚最艰难的一仗，你也会想借我们的力量吧。我们的力气可大了！」

「艾米莉，请注意说话方式。」

「我们可是非常可靠的啊！」

「非常可靠，尤其是艾米莉和加菲尔先生。」

艾米莉娅纠正了自己的说法，佩特拉也挺起胸膛说道。

艾米莉娅一行——加菲尔毫无疑问是最强的战士，艾米莉娅也相当有自信。奥托和佩特拉非常聪明，法兰黛莉卡则擅长体贴关心他人。

碧翠丝在与昴重逢之前无法发挥全部力量，正在休息中。但是，只要想到要保护她，就会激发起无穷的力量。

因此——

「有我们在，埃布尔的目的肯定更容易实现吧？却还只肯这样说话，是不想让人觉得，你开口求了我们吗？」

「――――」

「虽然罗兹瓦尔说『拜托了』这种话很拙劣……」

埃布尔和罗兹瓦尔一样，都不想让对方看到自己的弱点。

因此，他们总是试图引导对方说出什么。也许这种方式一直行得通，但是……

「在吃到大大的苦头之前，还是改掉比较好哦。别像罗兹瓦尔那样，被米迪娅姆、尤尔娜、兹克尔他们一人打一巴掌」

当初罗兹瓦尔谋划了波及宅邸与『圣域』的阴谋，最后挨了包括艾米莉娅在内、所有人一人一记耳光。

虽然亲自参与的艾米莉娅说这话有些奇怪，但那确实很疼。罗兹瓦尔锻炼有素，才只肿了脸，换成埃布尔会怎样，可就难说了。

即使不考虑埃布尔身体的问题，也是如此。

「我的话完全错了吗？如果是的话，那太丢人了，请说出来。如果那样，我也会道歉并考虑其他事情。」

「其他事情？」

「我不认为你是个脑中空空、不会考虑未来的人。所以，不断去想你究竟在思考什么，是很重要的事」

以前的艾米莉娅总是很快放弃自己无法理解的事情。

她总是很快找个借口放弃，并依赖帕克的话。近来，她经常向拉姆和奥托等擅长思考的人寻求帮助。

但是，这种方式不应该只是改变了依赖的对象。

佩特拉说，佛拉基亚的皇帝非常善于利用人。但是，善于利用人的皇帝肯定会考虑如何使用他们。

而那些在高位的人，必须能够成为众人的中心人物。

这就是艾米莉娅所选择的目标。

「——您能这样思考，实在令人安心。我很高兴，艾米莉」

艾米莉娅正神色凛然地面对埃布尔，身后便传来了这声赞许。无需回头，她也认得那熟悉的声音——是可靠的奥托。

他先前说有事情要调查，暂时另行行动。此刻想必也是有事要找这座市政厅——不，是有事找埃布尔。

「奥托也是来找埃布尔的吗？你一个人没事吧？」

「谢谢你的关心，但是不用担心……」

「是吗？可是，奥托以前也在大家没留神的时候被掳走过……」

「这还真叫人无从反驳！……不过，我也做了防备的」

面对艾米莉娅的担忧，奥托不禁拔高了声音。紧接着，加菲尔便从他身后露了面。看来，他陪着奥托一起去打探消息了。

艾米莉娅松了一口气，同时感激地说：

「谢谢你，加菲尔。」

「哈，这有啥好谢的。倒是艾米莉和佩特拉小姐，你俩刚才在说啥？」

「嗯，说了很多……不过，多亏佩特拉小姐，才没有被他绕进去。我没有被绕进去吧？」

「嗯，我们没事。非常可靠，让人惊讶呢。」

「呵呵，是吧？」

在奥托和加菲尔面前，艾米莉娅和佩特拉击掌庆祝。像加菲尔一样，艾米莉娅也为了保护佩特拉而努力。

奥托看着两人，眉眼柔和下来。但随即又唤了声「埃布尔先生」，隔着作战桌，正面望向那张鬼面。

「大致能猜出您与艾米莉她们谈了什么。雷姆小姐被『九神将』掳走，若目的地是帝都鲁普加纳，我们便已经站到了帝国的对立面——是这样的话题吧？」

「哇！太厉害了！奥托，你偷偷听到了吗？」

「偷听吗？」

「艾米莉也就罢了，怎么连佩特拉小姐也……我可没有偷听！」

「这样啊。那你还是很厉害嘛。」

「……他真的没偷听吗，加菲尔先生？」

「艾米莉也就罢了，佩特拉小姐还真是……」

艾米莉娅满脸佩服，佩特拉却向加菲尔求证。面对这截然不同的反应，猜中刚才谈话内容的奥托苦笑着，轻轻清了清嗓子。

接着，奥托望向埃布尔的眼神也变得严肃了起来。

「刚刚听了外面进来的人说，反叛的声音不断在各地响起。人们也在陆续汇聚到这里来了。」

「这里是起事之地，又曾击退『飞龙将』，自然如此。尤尔娜・米希格蕾率魔都居民以此为据点，也是一因」

「是啊，毕竟是令人惊叹的手笔呢。」

埃布尔淡淡地回答着，表示赞同奥托的话。

对于艾米莉娅而言，这些内容并不新鲜。在这几天里，聚集在古拉尔的人数很多，艾米莉娅也协助修缮着破损的住居。

不过，法兰黛莉卡和佩特拉叮嘱她尽量别做力气活，因此她主要以魔法冻结、加固立柱等方式帮忙。

总之，这些内容对于艾米莉娅来说并不是新鲜事。但她感到不安的原因，大概是奥托的态度。

奥托一如既往地沉静、聪慧而可靠。可艾米莉娅却从他温和的侧脸上，察觉到了一股藏也藏不住的怒意。

「布局到了什么地步呢？」

这一问，让艾米莉娅心中的疑惑化为了确信。

面对奥托的质问，埃布尔沉默不语。但艾米莉娅觉得，他并非在思考答案，只是在故意吊着对方。毕竟，他目光没有半分动摇，眼神也未改变，分明早已有了答案，却迟迟不肯说。

「究竟有多少事，正在依照您的意图发展呢」

奥托用另一种方式问了同一个问题。

艾米莉娅不认为奥托是被晾得不耐烦，才率先让步。她虽不喜欢用胜负看待事情，但眼下的胜负，其实早已分明。

奥托的态度，是要问问他失败的原因。然而，他的失败也是艾米莉娅等人的问题，他们面临着相同的问题。

「我回到这座城，才知道你们的存在。若连这都能算入谋划，那便得有解读星辰的本事了」

「那么，你认为这只是偶然吗？」

「我不打算把它归结为偶然。毕竟，运气只是决定因素之一。」

埃布尔摇了摇头，断然否定了奥托的话。看到奥托的脸色变得严肃，艾米莉娅不禁拉了拉他的袖子。这样，她就结束了让他一个人承受失败感的局面。

「奥托，这是怎么回事？」

「……关于菜月先生如今的处境，我们收到过说明。虽然事情实在荒唐得很」

「就是和米迪娅姆一样，变小了，对吧？」

听了奥托的话，佩特拉看了一眼身旁的米迪娅姆。米迪娅姆曾经讲过，在魔都遭到敌人的攻击后，从成年人变成了小孩子。不仅仅是她，昴也处于同样的状况。

为了保护处于不安全状态的昴，

「埃布尔散布了一个谣言，说拥有黑发黑眼的男孩是皇帝的孩子。这样，即使被那些对昴有恶意的人发现，他们也不会杀他......」

「为了确认真伪，对方会留下他的性命。当时我也认为这是妙计，只要能降低菜月先生的危险就好。然而——」

「可现在，似乎已经不是大将能保平安这么简单了」





加菲尔接过奥托的话，抱起双臂。「咦？」艾米莉娅转头看去，只见他咬响尖牙，

「城里涌进来的家伙，全都想跟皇帝开战。这事老子本来没什么可说的。可要是大将会有危险，那就是另一回事了」

「昴危险了......」

「......这样啊，原来是这个原因」

昴和雷姆都有可能在帝都鲁普加纳。

对于各种目的和思想相互关联的事情，艾米莉娅一个人难以理解。但是，加菲尔说出的疑问的答案很明显。

埃布尔做下的许多谋划，是为了将昴召到决战之地。

若他刻意安排这一切，又不愿被人看穿，此刻一定相当难堪。

那么，在这种情况下，如何减少说不出请求的情况？在什么情况下，可以向对方请求帮助？

把这些东西清晰地界定在自己的内心，这就是艾米莉娅现在的目标。

在鬼面的对面，两个人目光交汇，艾米莉娅突然发现：埃布尔永远不会同时眨眼。

他总是保持着一只眼睛不闭。眼睛不会干吗？

——他是否因为太努力而心灵也干涸了？

沉默许久，埃布尔终于开口，却要就此结束话题。艾米莉娅为这说法睁圆了眼睛，替她大声发话的却是米迪娅姆。

米迪娅姆又用力扯了一把袖子，朝埃布尔吐吐舌头。随后，她小跑着绕过作战桌，来到艾米莉娅等人面前。

「我也不知道麻烦的事。但如果雷姆小姐在帝都，那么阿哥也一定在那里......我想再次见到他们两个。还有昴先生！所以，所以......」

米迪娅姆竭尽全力地说着。

面对她的恳求，艾米莉娅柔和了目光，随后越过鞠躬的米迪娅姆，看向后方的埃布尔。

「我便将此视为，你们也会参与进攻帝都的表态」

两个年幼少女的斥责，响亮地落在了那个说不出『拜托了』的埃布尔身上。

将艾米莉娅视为敌人，为了报复上次在古拉尔的战斗，玛德琳挥舞着飞翼刃朝着眼前的艾米莉娅发动攻击——
