# 『战乱与战场』

------

——反乱的火焰，正一步步蔓延至佛拉基亚帝国全境。

这几天，帝国喧嚣不已，仿佛此前数年的安宁都是假象。积蓄于其内部、浓稠欲滴的嗜血欲望，如今正大声呼号。

佛拉基亚皇族历代以鲜血汇成大河——人们曾寄望当今皇帝，能终结这令人作呕的旧习。

实际上，在皇帝统治的时期，虽然有小小的纷争，但却避免了被称为大规模混乱的局面。

帝国人民本该享受到建国以来首次的『安宁』。

然而……

「打开盖子一看，帝国的人们原来并不渴望平静的生活」

托德坐在椅子上，看着摊在膝头、标明战况的地图，不无同情地喃喃说道。

他无从知晓皇帝文森特・佛拉基亚究竟抱着怎样的理念治理国家，但这份太平，想必不是什么偶然得来的成果。

以年为单位消耗着精力和体力，建立了帝国历史上前所未有的和平时代。

可到头来，却如此轻易地发现这一切根本不被人期待，皇帝心中的失落实在不难想象。——国民何其愚蠢，皇帝又何其可悲。

「换作是我，可不懂为什么要主动给自己多添送命的机会……脑子不正常的家伙，想法真搞不懂。那家伙也是……啊，呃，对，贾马尔什么的」

记得那个男人只要一有空，就会把帝国人的骄傲之类挂在嘴边。

回想着那个连面孔都已模糊的男人，托德・芬格重新打起精神。若说话不慎，让人发现他已经忘了贾马尔，那可就麻烦了。

至少，在自己珍爱的女人和必须好生应付的女人面前，他还得表现得像贾马尔依然活在心中一样。

「――托德，累了吗？」

突然，在托德看地图的视线边缘，他看到了一个倾斜身体的女人的脸。

老实说，对心脏不好。她刚才还在马车的屋顶上。他不知道她什么时候移到了旁边。

当然，世上这样的高手多得数不清。若对每个正面交手赢不了的对手都心生畏惧，那这世界也未免太难活了。

大多数人栽跟头，就是因为把打不赢与杀不掉混为一谈。

即使绝对不能赢，也有容易杀死的对手。

托德不认为这样的对手是威胁。因此，旁边的女人——亚拉基亚也是如此。

「托德？」

亚拉基亚从敞开的窗户滑入车内，坐上马车的长椅——不，她其实是毫无仪态地蜷起双膝，蹲在座位上。

听说她在帝都生活了不短的时间，却丝毫没学会城里人的礼数。

原因或许是她本人缺乏这方面的教养，又或是周围的人没有好好教导。像她这样的强者，往往因为实力强大，就被放任不管。

在佛拉基亚，无论什么事，强者都享有优先权。

正因如此，即使亚拉基亚举止不雅、行为无礼，也没人敢出声责备，恶性循环就此形成。当然，比她更强的人应该有资格指点她的礼数，可是——

「听说那位大名鼎鼎的『青色雷光』，可是比亚拉基亚还要不正常的家伙」

只要身在佛拉基亚帝国，便不愁听不到关于帝国最强『壹』的传闻。

本想说那些传闻好坏参半，可就连在帝国这个怪物横行的地方，关于『壹』的传闻也尽是被视作恶劣之举的事迹。怎么看都不像适合教导亚拉基亚的人选。

结果，亚拉基亚的种种举止便一直无人纠正。

不管怎样，托德也没有理由去纠正她。

「亚拉基亚，坐好。太不像样了」

「坐？我坐椅子？」

「还有别的吗？你认为椅子是什么？」

面对她一脸茫然的反问，托德如此责备道。亚拉基亚虽然仍感到不解，却还是老实地端正了坐姿。

不过她的双腿仍张着，托德便拍了拍她的膝盖，让她也把腿并拢。

「底下的人都看着强者的举止。帝国虽说强者做什么都行，可士兵也是有感情的。喜欢上司和讨厌上司，哪种情况下更容易打好仗，连你也不用想就明白吧」

「……有什么意义？这个。无论如何，我只是独自战斗。」

「你毁掉战场之后，谁来猎杀幸存者？谁来处理尸体？谁来和投降的人交涉？」

「――――」

「那么，如果你一个人很好，为什么我要在这里？你的话充满了矛盾」

托德一番适可而止的反驳，让亚拉基亚面露难色，沉默了下来。

好在如今他已能看懂，这并非帝国第二强者暗自积蓄不满、伺机发作的表情，而是觉得他的话确有几分道理。

起初，托德每次指出问题都得小心措辞，如今却已没了这份顾忌。

摸清了应付她的门道，管教亚拉基亚也就像是在驯养牧羊犬。

与牧羊狗不同的是，这只狗本身就是一只强大的狼。

不过，自己竟会这样想，也实在可笑。

「托德，累了吗？果然吗」

「真要说累，也只是接连赶路的旅途劳顿。你可真勤快，难怪皇帝阁下和宰相都这么倚重你」

「……有必要，所以」

见托德沉默不语，亚拉基亚又担心地问了一遍。他正面否认了她的忧虑，将话题抛了回去，亚拉基亚便低下了头。

想必亚拉基亚也知道，自己正被当作方便的工具使唤。

她不是会主动提起身世的人，托德也毫无兴趣，所以一直没有深问。不过，考虑到今后如何与她相处，或许还是该问一问。

若听过这些事就能让她单方面觉得与托德更亲近，那也是笔不会吃亏的买卖。

「你……」

「地图，你刚才在看什么？」

托德刚想开口，就被亚拉基亚转移话题打断了。他「唔」了一声，停下话头，将地图朝她倾斜，好让她也看得见。

这是一张佛拉基亚全境的简图，只标着主要城市和地形。托德凭着自己的判断，在上面添了许多标注。

当亚拉基亚仔细看着这张地图时，她皱起了漂亮的眉毛，说：

「……我不懂」

「想也是」

然而，对于那些不理解的话，托德并没有因此责怪亚拉基亚。

这并非他对亚拉基亚的学习能力死了心，单纯是因为那些标注，本就写成了除托德以外谁也看不懂的形式。

他并没有用什么特殊词语或符号，只是另赋其意，又故意混入错误的符号，使旁人即使看见，也无法从中获取情报。

这样一来，即使不慎遗失地图，也不会泄露托德的行动。万一沦为俘虏，对方为了让他解读地图，或许还会留他一命。

这就是为了避免栽跟头而多留的一手，做了总不会吃亏。

「有意义的标注，记录的是战斗发生的地点与规模。没意义的那些，只是障眼法。哪些是哪种，我就不跟你解释了」

「解释了，也看不懂。……很多吗？」

「啊，自从这位皇帝阁下即位以来，还从没有过这么难以收拾的局面」

这是一个没有主语的问题，但亚拉基亚的疑问是关于帝国全境发生的叛乱。

叛乱军不仅宣示了对皇帝的叛变，而且实际上也经常发生了帝国军队和叛乱军队的冲突，因此反叛的呼声在各地高涨并广泛传播。

而引燃这一切的，正是图谋夺取帝位的反乱军所拥立的大义象征——

「皇帝阁下的私生子，黑发的皇太子」

「阁下有孩子……真的？」

「谁知道。重要的不是是真是假，而是这种传闻已经传开，而且不仅没消失，反倒越烧越旺」

「——」

「所以才得把勤快人派往各地，顺带连我也一起」

作为皇帝亲自选出的『九神将』之一的亚拉基亚，当然有跟身在云端的文森特・佛拉基亚皇帝直接对话的资格。

虽不知亚拉基亚的判断究竟有多可信，但就连在她看来，反乱军拥立的皇帝私生子，也很值得怀疑。

但正如托德自己说的那样，这并不重要。

「如果不想被认为重要，就应该在火势未燃时就把谣言给消除了。结果就是这种乱局。」

「——关系到剑奴孤岛吗？」

「那是……」

托德闭起一只眼，被身旁亚拉基亚的一句话打断了话头。

她提起的剑奴孤岛基奴海布事件，是帝国宰相贝尔斯提兹秘密交给两人的第一项任务，也是他们失败得彻彻底底的任务。

就在几天前，两人奉命杀光岛上的剑奴，意气风发地出发，却在即将登岛前撤退，才得以安然无恙。

任务没有完成，自然遭到了贝尔斯提兹的斥责。但托德察觉危险的本能，坚决拒绝让他踏上那座岛。

他感到，岛上有着绝不能与之正面相对的威胁。

托德对这种感觉有着绝对的信心，他并不后悔当时没有登陆该岛。此后，剑奴孤岛被剑奴控制，并作为分散在各处的反叛事件的一部分继续扩散，这一事实对他来说不值一提，因为与他的生命相比，不值一提。如果托德曾经对当时的判断感到后悔，那么——

「真是愚蠢。不像我。」

「托德？」

「没什么。你担心的太多了。反叛在各处发生，但没有持久。只是在做梦。」

隔了这么久，托德才回答亚拉基亚先前的问题，耸了耸肩。

他无意蒙混，也不是假惺惺地为对方着想。反乱军确实在做梦——梦里虽快活，醒来却只会自我厌恶到恨不得去死，是那样一种噩梦。

也可能，他们连醒来的机会都没有，就会在噩梦中迎来终结。

正在托德说完这些话的时候，马车上传来了一个尖锐的声音：「亚拉基亚一将！芬格上等兵！已到达！」

马车慢慢停下，托德和亚拉基亚走出了马车。他们站在一座小山丘上，天空中有浓云，托德感觉天空不安地预示着帝国即将陷入内乱。当他把目光从这些诗意的景象中移开时，他看到了广阔的平原，上面有熟悉的军队在激烈地撞击，还有那些穿着陌生装备的军队。

帝国军和叛乱军，西部平原的冲突已经开始了。

「对方是什么人？」

已经布阵的帝国军中，一名士兵来到山丘上的两人面前。

托德劈头便问，对方顿时露出不快。看他披着斗篷，应该是位『将』。区区一名上等兵如此居高临下地发问，让他一时不知该作何反应。

但是，他发现了站在托德身边的亚拉基亚，并且立刻改变了他的态度：

「是库诺埃莱门特的居民。他们杀了执政官，正在那里耀武扬威。听说那位执政官才刚到任」

「偏偏赶上局势这么糟的时候调任，那执政官也够倒霉的……那么，那群干劲十足的家伙里，有那个瘟神吗？」

「目前还没有确认。我们认为没有。」

「如果有的话，他们一开始就会露面。亚拉基亚一将。」

「啊……」

听完那位『将』的报告，托德点了点头，叫住亚拉基亚。她轻轻应了一声，转过头来——眼下正是能让帝国第二强者尽情发挥实力的局面。

因此，只需要由托德来处理任何其他障碍。

「发信号，让士兵撤退。我建议他们什么都别管，一心往回撤。不然的话——」

「否则呢？」

「亚拉基亚一将的火焰不分敌我。」

这不是有意要威胁的话语，但对于听到这话的那名将领来说，它的效果同样不弱。

对方微微倒吸一口气，瞥向亚拉基亚。她依旧是一副不知在想什么的表情，察觉到视线后，便回望那位『将』。

与那只未被眼罩遮住的红瞳对上视线，『将』绷紧了脸，

「敲鼓！撤军！」

他立刻改变了态度，对他的部下们发出了尖锐的指令。

与那些不听话的兵卒不同，战场上有个明事理的『将』，沟通起来就是省事。不过，战场也不会因此变得有趣，还是尽快把这份讨厌的差事了结为好。

「亚拉基亚，听到鼓声往回撤的士兵，不许打中他们」

「其他人呢？」

「随你喜欢。」

这句话让亚拉基亚稍微有些困惑地眨了眨眼。

说得不好，托德很快就自我反省了。她是一个拥有破坏力的女人，但亚拉基亚似乎并不喜欢战斗。

因此，在战场上随心所欲不太合适——

「——抵抗的敌人都杀了。」

这样命令才是正确的。

「————」

太鼓的声音响彻天际，瞬间，从山丘俯瞰的战场发生了变化。

钢铁交击的兵刃声渐渐远去，取而代之的，是怒吼与咆哮。追击者与逃跑者的喊声，开始席卷战场。

然而，这也不会持续很长时间。

——从天而降的爆炎，将那些追赶着逃跑背影、自诩猎人的家伙烧成了灰。

眼前的战友、近旁的同胞，乃至自己的手脚被火焰吞没，他们才从狂热中惊醒，意识到——

自己根本不是猎人，而不过是任人猎杀的猎物。

「――――」

亚拉基亚一手握着如同孩童玩具般的树枝，双膝以下化作火焰，越过山丘，一路向上、向上，升入高高的天空，再从那里将烈焰倾泻而下。

足以改变世界颜色的恐怖战术兵器——眼前的景象，唯有如此形容才贴切。

火焰直扑地面，依照托德设下的条件烧灼敌人。那些看见敌人遭到焚烧，便停下脚步、还想趁机捞一份战功的人，做出了错误的判断。

一旦停下，亚拉基亚的火焰就无法将他们与该烧死的敌人区分开来。

「敲啊，敲啊，敲啊！敲响战鼓！所有人都给我回来——！！」

看到改变的战况，将军全力大喊。虽然帝国士兵都已经准备好在战场上死亡，但这与不惧怕无谓的死亡是完全不同的。如果留在那里，他们的评价将不会超过流浪狗被烧死。

因此——

「——芬格上等兵！阻止亚拉基亚一将！」

看着叛乱军的阵势崩溃，视野被火焰的魔鬼吞没，已经完成工作的托德的耳膜被怒吼冲击。

回头望去，并非刚才指挥撤退的那位『将』，而是另一名帝国兵，正顶着被煤烟熏黑的脸，神情急切地高声呼喊。

托德皱着眉头，问兵士发生了什么事。兵士被火焰照得脸色通红，说：

「对方已经提出投降！战斗结束了！」

「这种只图自己方便的要求，也能答应吗？说句不好听的，现在又不是不停手、我们也会受损失的局面。只要愿意，就能单方面把他们杀个精光。斩草除根、杀一儆百，还是做了为好」

只要用好亚拉基亚的力量，他们便能不损一兵而获胜。

与其接受投降，让对方得意忘形，不如拿他们作个榜样，叫他们后悔参与反乱——托德是这么想的。

然而，士兵接下来的话，却推翻了托德的这番想法。

「不行！投降的家伙带着『皇太子』！」

「什么？」

听见报告，托德不由一把揪住了对方的衣领。士兵喉间发出一声「呃」，托德却毫不理会，将脸凑近，

「为什么这里会冒出『皇太子』？不是说他不在吗？」

「他们一直隐藏着……现在才出现……」

「啧，想当成王牌吗？一群连自己手里牌的价值都不懂的家伙」

释放了手中的士兵，托德深深地吐了口气。

随后，他抬头看向空中盘旋的亚拉基亚，犹豫着要不要叫住她。思索片刻后，

「把使者带来」

「什么？但是……」

「带来。告诉他，不想全军覆没的话，就给我拼命跑过来」

对于托德平静的指令，士兵提出了反驳，但很快就意识到了毫无意义，转过身去。

托德也不想利用亚拉基亚的武力作为背景，但为了让事情快速发展，不得不采取这样的方法。

——因为对方拥有的是皇太子，这是最糟糕的情况。

「芬格上等兵」

过不了多久，先前的士兵回到了托德身边，带着一个穿着破烂的年轻人。尽管他身上穿着显示勇气的装备，但他脸上却有着认输的表情，这与他身上的装备形成了鲜明的对比。这是很正常的，即使是托德，如果他看到对方使用亚拉基亚的暴力，他也会有同样的感觉。虽然他怜悯对方，但仍有些事需要确认。

「听说你们那里有『皇太子』。这就是你们反乱的大义名分？」

「是、是的。『皇太子』希望登上帝位。我们认同他的志向，为了替那位大人开辟道路……」

「——那是假的」

「啊？」

托德一直盯着对方的脸，在那番大义凛然的说辞中插入了一句话。男人闻言，露出困惑，随之而来的却是更深的惊恐。

这反应让托德确信——自己的信口指控，并没有冤枉他。

「咔」

下一刻，托德挥出腰间的斧头，劈开了僵立在原地的男人的脑袋。

男子的头顶被斧头刺穿时，他发出了低声呻吟，眼睛猛地转动，倒塌在地。士兵看着托德立即消灭使者的举动，有些惊讶。

「上等兵！擅自行事……」

「他撒谎了。对面根本没有『皇太子』，一群连投降都选了蠢办法的家伙。——让亚拉基亚一将继续」

「如果，如果真的有『皇太子』呢？」

「没有。」

托德斩钉截铁的语气，让士兵再也说不出话，只能沉默。随后托德扬了扬下巴，士兵便拖走了倒在他脚边的敌人尸体。

托德用手擦去斧上的血肉，长长地吐了一口气。

他和亚拉基亚一起，巡视着各个地方，消灭反叛的源头，但每次都有『皇太子』的存在阻碍。

文森特・佛拉基亚的后代，是帝国各地反叛的合法性唯一的可能性，以此自称并策划反叛的人多得难以置信。

更麻烦的，是宰相贝尔斯提兹命令他们，尽可能将那位『皇太子』活捉，带回帝都。

「啊，真是的，没什么好说的。什么时候才能回到帝都呢？」

回到帝都的计划一次次失败，不知怎么回事却成了环绕帝国全土的旅程。

现在，想着被留在帝都的未婚妻，托德咬紧唇。

烈焰舔遍战场，将选择抵抗的人连同悔恨一起烧尽。

托德怜悯那些看不清这般未来、站错了位置的人，同时也蔑视着他们。

反乱终将覆灭。不论声势有多浩大，都不可能敌得过帝国这般庞然大物。

托德对此毫不怀疑，却又忽然想到。

「——」

内乱的开始和各地扩散的叛乱的火焰。

战乱的火焰，仿佛有人刻意安排一般不断蔓延。在那火焰的背后，有着某个人。

有着一个，不断、不断刺痛托德求生本能的人。

在看到燃烧的战乱和实际燃烧的战场的同时，托德静静地站着。

究竟是谁期望着这场吞噬佛拉基亚帝国的战乱？不管怎样，托德一定要读懂它，并不惜任何代价得到自己想要的东西。

不惜任何手段和思考，唯一令人担心的是。

『——。有关系吗？剑奴孤岛的事』

抵达战场前，亚拉基亚问过的那句话掠过脑海。

托德基本不会回顾过去。无论自己做过什么，他只会用后来的行动，将当初的选择变成正确答案。可唯独那件事，始终令他耿耿于怀。

他没有登陆，托德放弃了剑奴孤岛，并撤退了。

那个决定是正确的，他不应该后悔。

但是，如果因为某些原因而后悔，那么，

「——只有那天的撤退，让我的人生彻底陷入死局的时候」
