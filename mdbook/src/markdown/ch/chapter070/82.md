# 『反乱者的谋算』

------

「——说到底，只要控制住我，就能封住德拉克洛伊领的行动啊。罗兹瓦尔，你果然娶了位好夫人」

「……我都懒得数这是第几次纠正了，拉姆是我的侍从——啊」

身陷如此处境，塞琳娜却依然镇定得异乎寻常。罗兹瓦尔听得直想抱头，只能苦着脸回答。

在两天前，他们拜访了塞琳娜的德拉克洛伊领地，并请求她在佛拉基亚帝国寻找失踪的昴和雷姆，为他们提供帮助。

塞琳娜身居上级伯之位，在帝国内人脉甚广。只要告诉她要找的是『黑发黑瞳、想不引人注目都难的少年』，想必就能获得相当可靠的消息。

无论被传送到哪里，昴都不可能老老实实地待着。从这个意义上说，罗兹瓦尔也对这次寻人抱有很大的期待。

因此，这样的结果在某种意义上是必然的，同时也是出乎意料的。

「拉姆，我还是问一下，这次行动的原因是……」

「──夏美・施瓦茨」

「就是这个了啊」

从拉姆的嘴里吐出的名字，对罗兹瓦尔来说也是无法忽视的。

那是被送往帝国并孤立无援的菜月・昴向能理解那个名字意义的人发出的求救信号──罗兹瓦尔和拉姆也立刻领会到了他的意图。

用这种方式告诉同伴自己就在这里，昴这次的判断难得地无可挑剔。没错，单就昴的行动而言，并没有任何过错。

问题在于，这道求救的狼烟，是从哪个『阵营』升起的。

正因如此，拉姆采取了近乎突袭和暴行的手段。

这样的结果，就是塞琳娜被拉姆用魔杖逼迫，坐在了沙发上。然而，这不能完全归咎于拉姆的暴走。

因为──

「──与反叛军一同的『黑发少女』，夏美・施瓦茨是你们要找的人吗？」

「严格来说，对拉姆来说那是附赠品」

「但对罗兹瓦尔来说并非如此。而对罗兹瓦尔来说并非如此，对你来说应该是非常重要的事情」

被魔杖指着、行动受制的塞琳娜说出了这番话，让拉姆闭上了嘴。

尽管被拉姆制住，塞琳娜的头脑仍在敏锐地运转。即便身处这种局面，她也未失从容，已经大致摸清了两人的处境。

──『夏美・施瓦茨』是菜月・昴用来自称的化名。

准确地说，这个名字还有更复杂的含义，但只要推测昴为何要在帝国使用这个名字，他赋予这个化名的意图便显而易见。

罗兹瓦尔本来也希望尊重这个意愿──然而，

「竟然，是与反叛军一起……」

虽然能理解使用化名的意图，但狼烟升起的方向却出乎意料。

本来在帝国潜入期间爆发的叛乱就是一个令人烦恼的问题。如今这个问题不仅没有解决，反而如同绽放出毒花般恶化。

不论是好是坏，情况不按照他们的预想发展，实在是典型的昴作风。

「拉姆，你是不是也被昴带坏了——啊？」

「这真是岂有此理。拉姆的行动，哪怕一丝一毫也不会受到那个巴鲁斯的影响」

「可是，事到如今，这种局面不正是因为他的行动而产生的吗？」

「罗兹瓦尔大人，请与塞琳娜大人谈谈」

一旦事情变得不利，她便巧妙地改变话题，并将主导权推给别人。

拉姆大胆的谈话技巧让罗兹瓦尔眯起了一只眼，他重新面对塞琳娜。

目前，罗兹瓦尔和拉姆被召唤到了她的办公室，在这里，他们亲自听到了她提起『黑发少女』。

两人已经将昴和雷姆的外貌特征告诉了她。对她而言，大概只是注意到『黑发』这一点相符，便随口拿来当作谈资。但这个消息对罗兹瓦尔他们，却有着绝不能忽视的意义。

塞琳娜刚说完「城郭都市出了这种事，身为上级伯，我也必须表明某种态度」，拉姆就动手制伏了她。

胆大的塞琳娜，由于她没有在办公室安排护卫，这也招致了灾祸。

私人兵力正在房间外的走廊待命，他们并没有注意到室内的紧张气氛。当然，只要塞琳娜一声令下，他们会立即冲进办公室。

「那样的话，拉姆就会将塞琳娜大人碎尸万段」

「哦，真可怕。听得出不是虚张声势，而是当真的，正合我的胃口。罗兹瓦尔，你——」

「她是我的侍从，而不是伴侣……关于那个话题就此打住吧。比起这个，我们三人之间的关系能够恢复到和平状态，这才是我们想要努力的方向吧」

「你说『我们』，真是可爱。总是把一切当作别人的事的你，现在竟然试图承担起问题，给人一种新鲜的感觉」

塞琳娜含着笑对这番话，罗兹瓦尔眯着一只眼叹了口气。

确实如她所说，由于拉姆的行为，他不能再将问题当作与己无关。这不仅仅是主仆关系和责任所在的问题，还涉及到感情。

而且，拉姆的行动固然仓促，却也是为了抢占先机，宁可粗暴行事也要立刻采取措施。

毕竟，如果拉姆没有制约住塞琳娜——

「你引以为傲的『飞龙队』会在瞬间将反叛军烧成灰烬」

「——」

听到罗兹瓦尔的话，塞琳娜・德拉克洛伊微微眯起了眼睛。

德拉克洛伊伯拥有的『飞龙队』——那是在佛拉基亚帝国内驯服了大量飞龙，并且能随心所欲地飞行的帝国最强攻击部队。

掌握『飞龙操控』之术、能驾驭不亲近人类的飞龙的骑士，在战场上有着压倒性的战斗力。罗兹瓦尔自己也能飞行，足以让大多数对手毫无还手之力，因此尤其明白——夺取制空权，正是掌控战局的决定性手段。

因此，在佛拉基亚帝国，拥有优秀飞龙骑士的家族更容易取得战果。

德拉克洛伊伯爵家早在先代以前就擅长此道，到了塞琳娜・德拉克洛伊这一代，更被认为拥有最强的『飞龙队』。

如果她真的全力动用『飞龙队』，大部分的反叛军简直不值一提。

「没想到要找的人竟然加入了反乱军，这下你们可不能让我出兵了。不过，总不能永远在这里跟我大眼瞪小眼吧？你们准备怎么让我听话？」

「塞琳娜大人，您的家人呢？」

「寻找亲属是没有意义的。自从被罗兹瓦尔拒绝之后，就一直没有找到合适的人选」

「罗兹瓦尔大人？」

「别把玩笑当真。总之，王国和帝国的大贵族之间这种关系，在两国关系上是不可能的。塞琳娜，现在不是开玩笑的时候」

即使不考虑罗兹瓦尔和塞琳娜的关系，现在的拉姆也不能说是有耐心。

虽然表面上不太看得出来，拉姆却一直对普雷阿迪斯监视塔发生的事深感懊悔。没能守住昴和雷姆，最终与他们失散，她将这一切都归咎于自己的过失。

这次极端行动背后，她的焦虑毫无疑问也是其中一个原因。

「别再无谓地刺激拉姆了，我们一起想个双方都能接受的办法吧」

「双方都能接受的办法啊。那么，你们具体想要什么？」

「——」

「没有哪个蠢货会连目的地都不定，就让飞龙起飞。那可是消耗极大、骑手也十分宝贵的东西。要说白费力气，这才是白费力气。你也该体谅我的辛苦吧，嗯？」

撑着脸颊，塞琳娜像是在试探罗兹瓦尔的反应。

有昴参与的反叛军，再加上雷姆很可能也在那里，拉姆急切地做出判断也是情有可原。即使责怪这件事，时光无法倒流，也是毫无意义的。

要是有心，他们完全可以伤害塞琳娜，在混乱中逃离领地。

但那是放弃最初目的、徒增敌人的愚行。即便在实力至上的帝国，士兵们也不至于愚蠢到会为主人遭人暗算而死拍手称快。

削弱拥有『飞龙队』的德拉克洛伊伯爵的力量，反乱军或许会乐见其成。然而，为此赔上旧友的性命是否值得，罗兹瓦尔也心存疑问。

无论如何，如果为了实现悲愿而需要牺牲，罗兹瓦尔也会毫不犹豫地牺牲塞琳娜的生命。

但是，如果没有必要牺牲，他并不想故意这么做。

因此，在这里罗兹瓦尔对塞琳娜提出的建议是——

「——怎么样，你愿意和我们一起加入反叛军吗？」

「啊？」

「这样一来，你我之间的冲突就能化解。只要目标一致，拉姆也就没有理由继续用魔杖指着你。双方都能圆满收场」

双手合十在胸前，罗兹瓦尔这么说，让塞琳娜目瞪口呆。

从她的眼中闪过的是惊讶、愕然，还有一丝好奇心。从激起她兴趣的角度来看，这并不是完全离谱的言论。

罗兹瓦尔凭借这点，努力拉近他与塞琳娜的关系。

「你说圆满收场，那也仅限于这个房间里吧。答应你的邀请，接下来就要投身内乱。皇帝阁下已经保障了我对这片领地的统治，无端生事又有什么好处——」

「——对皇帝阁下毫无不满。真的是这样吗？」

理智有条理地说出自己立场稳固的塞琳娜，然而罗兹瓦尔却打断了她的话，直视着她的双眼。

作为帝国的上级伯爵，表面豪放磊落的塞琳娜也是个擅长权谋的人才。正因如此，这个话题必须要在直视对方眼睛的情况下进行。

『和别人说话的时候，一定要好好看着对方的脸说话哦！』

突然，这样的话语在罗兹瓦尔的脑海中闪过。

在这种意想不到的情况下，被这句话激励着——

「这两天我并非在这里安然度日。在你忙碌的时候，我尽量留意了周围的情况。」

「原来你是在不陪我喝酒到天亮的时候，用心去偷听别人的话啊。」

「我建议你还是改掉每天喝酒到天亮的习惯，考虑到你的工作量。」

想来招待客人的日子与平时不同，但作为老朋友，他仍真心希望塞琳娜能少喝一些。

无论如何，在顾虑塞琳娜的肝脏健康之余，罗兹瓦尔展示了他偷听到的成果。这个德拉克洛伊领地秘密面临的困境，那就是——

「前年的未遂暗杀事件，传闻其中有『九神将』的参与，这件事情带来的影响似乎相当长久。」

「……」

「执行暗杀、并在事件中丧命的那位『九神将』，是名飞龙骑士……而且听说，原本还是你的部下。名字是……」

「——巴罗伊・特梅格里夫。」

塞琳娜用低沉、平静的声音说道，打断了罗兹瓦尔的话。

她依旧托着腮，眼底的情绪却变了。那抹仿佛连眼下处境都能乐在其中的神色消失，取而代之的，是无风湖面般的静寂。

她带着那样平静的目光，看向罗兹瓦尔斜后方的拉姆，

「拉姆，放下魔杖。就算没有它，我也会跟你们谈判的。」

「可是……」

「拉姆，照她说的做。塞琳娜说话算话」

罗兹瓦尔举手制止，拉姆勉强放下了魔杖。

当然，她还是保持着随时可以重新做好准备的姿势，但塞琳娜并没有责怪她的警惕。只是，她将脸转向窗户，看向那里展开的景色——不，是抬头仰望天空。

飞龙展翅翱翔，自由地在空中飞舞。

「你觉得这片天空是自由的吗？」

「从你的口气来看，似乎并非如此呢。」

「帝国的水、土、空气，乃至人的血肉，都是皇帝阁下的财产。这甚至包括天空。——是谁泄露的？」

「要限定某个人的话，恐怕有点困难。毕竟，这是大家都在想的事情。」

罗兹瓦尔耸耸肩，塞琳娜简短地回答说：「是吗」。

她说出的名字——巴罗伊・特梅格里夫，是前『九神将』之一，也是前年发生在帝都的皇帝暗杀未遂事件的执行者。

他原本是塞琳娜在德拉克洛伊领地内重用的人才，凭借非凡的实力和卓越的飞龙骑士技艺，从草根一步步晋升成了一将，似乎是一个极具潜力的人才。

当然，巴罗伊向皇帝刀兵相向，举荐他的塞琳娜也因此处境恶化。

虽未被剥夺上级伯之位，她在帝都却已失去信任。她麾下的飞龙队不再被寄予厚望，也得不到挽回声誉的机会。

更糟糕的是，取代巴罗伊成为『九神将』的人选——、

「——『飞龙将』玛德琳・艾沙尔，简直就像是在挑衅般的人选呢。」

「没有从军经历，仅凭宰相举荐就一跃成为一将。而她的真面目，居然还是个龙人。龙人不靠『飞龙操控』的秘术就能驾驭飞龙，相比之下，还要费时费力培养骑手的飞龙骑士，岂不显得绕了远路」

「这可让拥有飞龙队的塞琳娜大人无处自容了」

「哎呀，别小瞧我的飞龙队哦。不需要骑手也有优缺点。确实可以省去培训的麻烦，但没有骑手的飞龙在战术上只能依赖本能。而飞龙骑士在战术理解和应用方面有着优势。」

「————」

「不过，听说那个龙人连这点劣势，也能凭绝对的数量碾过去」

佛拉基亚的秘传『飞龙操控』——役使生性凶暴、不亲近人类的飞龙的方法，连罗兹瓦尔都不知其详。他只听说，想驯服一头飞龙，就需要一名有天赋的飞龙骑士始终陪在左右。

换句话说，飞龙骑士必须与一头飞龙成为一对伙伴。

相比之下，无需耗费时间就能驱使无数飞龙的『飞龙将』，对于以飞龙队为长的塞琳娜而言，无疑是天敌，也是眼中钉。

「巴罗伊是跟随我多年的心腹。他违抗阁下，甚至将枪尖指向阁下，罪责会牵连到我身上，也是理所当然。但是——」

「要不要甘受这份屈辱，就是另一回事了吧？」

「——你还真是句句都搔到我的心坎上」

「不敢当」

拉姆用平静的语气回应并鞠了个躬，塞琳娜深深地吐出一口气。

对于罗兹瓦尔和拉姆以不同语气提出的追问，塞琳娜都没有否认。从要求拉姆放下魔杖的那一刻起，她就已经做出了某种决断。

这表明她并不是在被威胁之下说出真相，而是以平等的眼光来进行对话的姿态。

换句话说——、

「——我本来并不打算在你们在这里的时候搅动风波的，明白吗？」

这么说着，塞琳娜・德拉克洛伊触摸着脸上的白色刀痕，獰猛地笑了。

那充满野性的笑容，正如年轻的罗兹瓦尔初次遇见她时所见，也如同在从父亲那里夺取家督之前表现出的雄心勃勃的笑容。

然而这次，那笑容所指向的，不再是因女儿夺走家臣信任而双眼蒙翳的父亲，而是统治这辽阔帝国、令人敬畏的存在——。

「——原来如此，塞琳娜，你是」

看到那个笑容，罗兹瓦尔终于意识到自己的误解。

本来他打算通过明确德拉克洛伊领地的立场，引导塞琳娜的想法，以避免拉姆草率行动造成的局势恶化，但这是个错误。

根本不需要引导她参与叛乱。

『黑发少女』参与的叛军崛起，对于她来说，仅仅是一个契机。塞琳娜已经做出了决定，并尽她所能地考虑到了罗兹瓦尔他们的立场。

她本来是想尽量不让毫不知情、前来寻人的旧友卷入其中，表现出了她独特的关心。

然而，罗兹瓦尔他们却毫无顾忌地闯入了对方的阵地。他们甚至没有察觉到魔石已经点燃，还在向其注入魔力。

换句话说——、

「我已经尽量照顾你们了。这一次，就怨你娶了个太机灵的妻子吧。又或者，兜兜转转，还是该怨你当年拒绝了我的求婚」

「塞琳娜」

「放心。揭露你的身份，只会让我被怀疑与王国私通。落到两面作战的境地，那才是疯了。要打，我就打有胜算的仗」

谈话的主导权被夺走，塞琳娜与罗兹瓦尔的局势发生了逆转。

既然立场一致，罗兹瓦尔他们就没有伤害塞琳娜的理由。反过来，塞琳娜却握住了两人的难处，大可从容地拿捏他们。

「罗兹瓦尔大人，难道说……」

「啊，看来我们是结结实实地闯进猛兽的猎场了——呢。——塞琳娜，如果我们没有主动提出来呢？」

「那时候我会适当款待你们几天，在内乱全面爆发之前把你们送出去。但是，既然被老朋友邀请一起战斗，就别无选择了吧。」

「真会装模作样……」

究竟是打算响应这次叛乱，还是另有计划采取某种行动，尚不明确。但塞琳娜已经下定决心要反抗。

是因为皇帝冷酷的行径引发的愤怒，还是与她亲信丧命的事实有关，这一点并不清楚。

只有一件事可以肯定——、

「对文森特・佛拉基亚皇帝阁下这番太平统治心怀不满的人，比想象中还要多。一旦燃起一场大火，便会顷刻燎原」

「……这把火会从哪里烧起，你心里有数——吗？」

「谁知道呢。倒是你，不也有想到的人选吗？」

含笑的塞琳娜似乎在暗示，她还有罗兹瓦尔所不知道的底牌。

而罗兹瓦尔心里，同样有这么一个人物。虽然不知他在这片陌生土地上能发挥多少力量，但若任其行动，必然会掀起非同寻常的波澜。

是他的话，无论陷入怎样的困境，总能设法闯过去。剩下的问题，就在于他会在困境中遇到什么人，有多么想救下那些人，又会让这份影响扩散到何种地步。

也许——、

「——甚至可能让整个帝国都燃烧起来吗，昴？」

如果真的是那样的话，罗兹瓦尔应该如何行动呢？

无论如何，为了实现他的悲愿，他必须带着齐全的队伍回到王国。即使不是这样，他也和昴有约定。

虽然那是罗兹瓦尔单方面强加给他的约定，昴却不可能将其抛诸脑后。既然决意拯救所有人，就不可能接受任何一人缺席的未来。

即便没有与罗兹瓦尔的约定，昴也会为了每一个向其伸出援手的人，挣扎到底。

那么，罗兹瓦尔至少要采取行动，让他少经历几次尝试。

只要不让昴察觉，事情正朝着昴不愿看到的方向发展，就足够了。

「那么，多亏了拉姆让我的生命陷入危险，现在我们之间的隔阂消失了。今天就不再工作了，干脆开瓶庆祝的酒吧。」

「虽然是举着杖的拉姆说这话，这样做真的没问题吗？」

「我们都需要为了相同的目标增强团结力。所以，喝酒增进友谊。想想我们的对手，这是再自然不过的事情了。」

塞琳娜若无其事地忘记了刚才的冲动行为，平静地邀请拉姆喝酒。

塞琳娜彻底敞开心扉，不必再对罗兹瓦尔他们隐瞒，显得神清气爽。这般大人物的气度，令拉姆也难得地不知所措。

尽管如此，他们并不认为塞琳娜会在此时用花言巧语欺骗罗兹瓦尔他们，做出捅刀子的愚蠢举动。

毕竟真这么做，她固然能让罗兹瓦尔在帝国失去自由，却也会让实现自身目的所需的战力，乃至自己的性命，都陷入危险。

「那么，你是打算等别人点火，还是亲自成为那把火？」

「我清楚自己的位置。不必着急，时候不远了。——还是说，你想到的那个人，是会安分守己的性子？」

「……那可不是」

「对吧？我想到的那个也是」

两人心中所想的『火种』应该并非同一人，对他们的看法却似乎颇为相近。

罗兹瓦尔在思索着这个事实，双臂交叉。与此同时，塞琳娜平静地走向她的饰品柜，开始挑选要喝的酒。

「罗兹瓦尔大人，关于城郭都市」

「就地理位置来说，从东方进攻的艾米莉娅她们要近一些。他们那边也会听到同样的传闻，如果能够汇合的话，应该会这么做。当然，这对你来说可能会感到焦躁」

「……不」

拉姆摇了摇头，将内心的焦躁压抑住，回答道。

实际上，她应该渴望尽早与雷姆重逢。如果在城郭都市听到了关于昴的传闻，那么雷姆很可能就在那里。

另一方面，即使罗兹瓦尔使用了飞行魔法，如果空手而归的话，也会受到很大的打击。

在广阔的帝国寻人，需要某种程度上压抑内心的理性。

「正因为如此，我们应该等待。就像她所说的，等待火势升起」

「――好的」

经过一番犹豫和迟疑，拉姆仍强忍着心情，点头应下。

――几天后，塞琳娜・德拉克洛伊所说的『火势』升起了。

以皇帝文森特・佛拉基亚之子为旗帜的反乱军，其声势迅速燎原，传遍帝国全境，影响了各地的反乱势力。

在此过程中，最早宣布加入反叛军的是德拉克洛伊上级伯，据说在勇敢的女领主身边，有一位英俊潇洒的陌生人和一个可爱的随从相伴。
