# 『反派却毫不张扬』

------

「喀喀喀喀！谁能想到，老夫这种人竟不是死在战场，而是在安全的地方咽气呢。寿终正寝的忍者，老夫可听都没听说过，真是讽刺得过了头啊。」

说罢，这位怪老一边放声大笑，一边挥舞着空无一物的袖子，他已经失去了双手。听着他那豪爽的笑声，加菲尔心情复杂，因为他知道治愈魔法的力量已经无能为力。

那场与『大灾』的战斗之后，加菲尔加入了医疗队，负责治疗伤员。自从来到帝国以来，他几乎没有休息过，一直在进行命悬一线的激战。显然，伙伴们都纷纷劝他先休息，但加菲尔却静不下来。

幸好，加菲尔的身体非常强壮，『地灵的加护』使得他站在地面上就能得到最好的休息。在艾米莉娅阵营中，加菲尔是最不容易过劳死的。反过来说，最容易过劳死的自然是奥托。

总之——

『一旦决定要做，说什么都没用了吧？那就干脆能卖多少人情，就给帝国卖多少。现在正是让人领情的好时候。』

尽管在所有人都反对加菲尔的决定时，只有她一个人明确表示支持。他的意中人用了露骨的话语，但他很喜欢她这样的风格。

因此，加菲尔在同伴们的惊愕中自愿承担了这个任务。最终，没有人阻止他，大概是因为大家都明白他的决心。

「最难受的大将都在那么拼，咱们怎么能在这儿干磨蹭啊。」加菲尔低声说着，咬得尖锐的犬齿咔咔作响。

失去的是一位强大、真正强大的女性。虽然他并未与她肩并肩战斗过，但在帝都几次见到的炽热火焰的光辉，早已在加菲尔的眼中深深印刻。

这不仅仅是艾米莉娅的对手消失了所带来的失落感。

所以，才是加菲尔。

要尽可能地阻止生命逝去。正是这双毫不留情地击碎尸人、有时也必须用蛮力排除同伴面前敌人的手，此刻要将生命救回来。

虽然这看似矛盾，但没有关系。加菲尔不去深思复杂的问题，而是凭借心意行动。

凭借心意，用自己的力量击败敌人，治疗并拯救同伴。

如果加菲尔能够通过牺牲睡眠来拯救更多的人，那么他会一直这样做下去。

「……真是的，这群年轻人总是这么快地甩下老人不管。真是让人又爱又恨啊。」

「你是在讽刺我吗，老爷子？就因为你的断臂我治不好，你就在这嘲笑我……」

「哈哈哈哈！哪里有什么讽刺啊。我告诉你，羡慕和嫉妒可是我几十年来的原动力啊！我说羡慕可不是开玩笑的。啊，真是羡慕又嫉妒。」

奥尔巴特一边晃动着他长长的白眉，一边灵巧地用脚挠了挠自己的脖子。虽然他失去了双手，但却毫不显得不便。这样的态度既可能是为了照顾那治愈魔法不起作用的加菲尔，也有可能是为了取笑他，实在让人分不清。

不管怎样，除开他的断臂不谈，能在几乎半死不活的状态下还保持这样行动自如，确实说明这个老人也是个怪物。若要说起那些濒死之际还能生还的经历——

「——啰啰嗦嗦吵死了，混账老头！人家累得要死还在拼命干活，少他妈缠着人家不放！」

「哎呀呀，真是可怕啊。这可不像是半死不活的样子啊。」

奥尔巴特听到深处床上人影爆发出的怒吼，低声笑了出来。那凛凛的气势使得加菲尔只能挠着头，无奈道：「真是的……」

「谢了，你替我说话。不过先顾好你自己吧。你可真是差一点就死了……都快到了『维维洛罗来送行』的地步啊。」

「啊？我不是说了吗，亏了你这家伙我才得救的！你敢说不接受我的感谢的话……呜咯嗷！」

「闭嘴，给我躺下！」

加菲尔用手按了一下这矮小家伙的头，对方顿时全身疼得惨叫，仰面倒下。这样的重伤会如此也是当然，就算竭尽全力持续施展治愈魔法，也赶不上伤势的严重程度。

实际上，即使是现在，他应该也依然在忍受着剧烈的疼痛。

「虽然我也没资格说你，但亏你还能醒着说话啊。」

「什么他妈疼啊、难受啊，哪能拦得住格鲁比・加姆雷特大爷！那种玩意儿，用毒用药糊弄过去就……呜哦哦……！」

「别逞强了。无视全身的警报信号的结果就是你现在的模样。和我这个失去双手的人，濒死程度几乎是不分上下。要不要考虑退役？」

「去你的，混蛋！」

斥责奥尔巴特的是格鲁比・加姆雷特——『九神将』之一，也可能是帝国中最接近死亡并且生还的人物。

在与『大灾』的死战中，他所发挥的作用极其重要。毕竟，他与赫鲁贝尔合作击退了『爱丽丝与荆棘之王』的主角、『荆棘帝』尤加尔多・佛拉基亚的诅咒，成为胜利的关键人物。

「要不是你干了那件事，大家恐怕早已被荆棘束缚，动弹不得了。」

「不过是做了自己该做的事罢了。送走『荆棘帝』和礼赞者之后，我只是躺在那里，直到把『邪剑』交给塞西尔斯。」

格鲁比嘴上闹着别扭，可直到躺下为止，他立下的功劳实在太大。他竟将尤加尔多的诅咒转移到自己身上，再让『邪剑』连同自己一起斩下——这种事，听多少遍都让人难以理解。然而在格鲁比等人看来，能与『云龙』交手的加菲尔也同样不可理喻，倒是谁也别说谁了。

每个人都竭尽全力，创下奇迹，这就是当时在帝都——不，整个帝国发生的现实。无论是与『云龙』战斗的加菲尔，还是从荆棘中解救『荆棘帝』的格鲁比，亦或是断了一只手来阻止『魔女』阴谋的奥尔巴特，他们都全力以赴。

对于他们的功绩，无需过分称颂，也无需歪曲事实。

「嘛，以一个活不久的老头子来看，看到年轻的一个个离去也挺难受的，所以看到你们活下来我还是挺高兴的。」

「……我自己倒是无所谓，可那家伙能否算是活下来了还是个大问题。」

「所谓那家伙是指……」

想到他们所说的那个人，加菲尔将目光投向治疗室角落，发现一个格外显眼的身影正直挺挺地站在那里。人们仍在忙碌地奔走、照顾伤者，那钢铁身躯却静立于不碍事的墙边，仿佛与墙融为一体。

那存在察觉到加菲尔的目光后，在他认为是头部的位置上镶嵌的绿色宝石闪动了一下，说道：

「我，察觉视线。猜测是有事、有命令、有指示之一。」

这么说着，慢慢靠近加菲尔他们的是被称为『钢人』的莫古洛・哈加涅，也是一位『九神将』之一。

更准确地说，钢人是一个种族的名称，而他的真身其实是水晶宫的核心——『流星』。尽管现在水晶宫和魔晶炮已经崩溃，这个头衔也不再具有任何意义——

「啊——，不好意思。只是恰巧看到你们那边，并没有什么事。」

「了解。其他两人呢？」

「也没什么事。别碍事就行了，就在那边待着吧，莫古洛。」

「莫古洛。那就是我。明白。等待进一步指示。」

在加菲尔面露尴尬之际，格鲁比扬起下巴指示道，而莫古洛也乖乖地遵照他的指示，靠在床边坐了下来。

这模样像是一个大一些的摆设。

「像驯服的地龙和雷狼那样听话。不过真是让人惊讶，连水晶宫也会忘事吗？」

「水晶宫和魔晶炮都已经被炸得粉碎了。莫古洛的核心能保存下来真是奇迹。还恰巧掉在我睡觉的附近，真是太巧了。」

「也许是因为和你最亲，所以它来找你了吧？」

凯凯地笑着，奥尔巴特轻松地说着俏皮话，而格鲁比则不满地哼了一声。

正如他们的对话所暗示的那样，莫古洛・哈加涅对『大灾』之前的事情一无所知。按照昴的说法，这种状态被称为『初始化』，意味着这颗『流星』曾经积累的所有记忆和经历都已被彻底清空。

帝都曾面临被彻底摧毁的巨大危机，莫古洛・哈加涅强行压制住了那股力量，飞升到空中以避免波及周围，并最终在空中爆发。因此，这样的代价或许还能算轻的。

「不过，有雷姆的事在，我怎么说得出那种话啊。」

加菲尔深深体会到丧失记忆有多么沉重。失去记忆不仅让本人痛苦，也让周围的人深受打击。

虽然并不想随意说「我能理解你的感受」这种轻率的话，

「说不定，这老头子的话也不全是错的。」

「啊？你连你这混蛋也要拿这种事来取笑我吗？」

「才不是。的确，他可能什么都不记得了，但你注意到了吗？他一直没有离开你身边。」

这样说着，加菲尔眯起眼睛看向坐在病床旁的莫古洛。虽然他那庞大的身躯占据了治愈室确实有些碍事，但他尽可能地紧凑自己以不打扰他人为宗旨，这一点让人不禁对其心生好感。

说到底，莫古洛执意留在这里，大概是不愿离开格鲁比的身边。失去『记忆』后，第一认知的对象似乎对其产生了一种印记。或者说，当拉姆和雷姆在帝国重逢之时，雷姆曾提到那种奇妙的感觉，让她立刻直觉地认出了拉姆是自己的姐姐。这种『某种东西』大概仍然残留在莫古洛的心中。

「真是的，大将说雷姆那家伙一上来就把他手指折断了……」

也有这种『什么』没能留下的例子，不能一概而论。然而，这里本就是疗愈他人的治疗室。倘若莫古洛孤身置于这个举目无亲的地方，是来这里抚慰心灵的，加菲尔便没有赶走他的理由。

「倒不如说，整天只会说话却帮不上忙的老头子才是真碍事啊。」

「喀喀喀喀！你这小子还真敢说！不过，确实如此啊。」

加菲尔耸了耸肩，奥尔巴特挥着空荡荡的袖子大笑。不理会两人的交谈，格鲁比揉了揉自己的黑鼻头，望向莫古洛——那个曾是自己战友的家伙，此刻一动不动，只静静地陪在身旁。

「唉，别搞得这么感伤，混蛋。」格鲁比愤愤地说道。

「检测到发言中的水声。恐有异常，请下达指示。」莫古洛机械地回应。

「该死的，给我闭嘴！」格鲁比怒吼。

「了解。」莫古洛回答。

在这没有结果的对话中，加菲尔咧嘴一笑，露出了他的獠牙。他笑出声后，内心稍微纠结了一下是否应该笑，但最终还是顺从心意，放声大笑了起来。

「——那么，安娜塔西娅大人计划通过卡拉拉基返回露格尼卡吗？」

「是的，正有此意。毕竟，我是以卡拉拉基特使的身份进入帝国的。虽然大家都知道这不过是个幌子，但我仍需认真履行这一职责。」

安娜塔西娅露出温柔的微笑，坦率地透露了内情。奥托在一旁平静地接受了这一切，并表面上毫不在意地回答道：「明白了。」

然而，奥托的内心远不如表情那般平静。无论如何，安娜塔西娅已经履行了与卡拉拉基都市国家的约定。派遣她前来的卡拉拉基评议会必然会提高对她的评价，为她的王选再添一阵实实在在的顺风。

当然，艾米莉娅在佛拉基亚帝国面临存亡危机时，也从皇帝文森特那里直接接到了救援请求，并在与『大灾』的战斗中做出了巨大贡献。虽然他们进入帝国时是以偷渡者的身份，但现在可以说，他们回国时将带着堂堂正正的凯旋礼物。

尽管如此，考虑到在普利斯提拉与魔女教的战斗、普雷阿迪斯监视塔的攻略，以及佛拉基亚帝国的救援中，不仅仅是他们艾米莉娅阵营，还有安娜塔西娅阵营的参与，这并不理想。我们需要艾米莉娅独自的名声，而不是与安娜塔西娅并列。

当然，如果在此次帝国遭遇『大灾』的战斗中没有做出贡献，他们的阵营地位将远不止是落后。

「有这么多事情要考虑，奥托君也真不容易啊？」

这一瞬间的沉默，被安娜塔西娅浅葱色的眼神打破了。

这大概是试探的话语，然而却让人感觉到安娜塔西娅似乎有某种确凿的把握。这是因为她在多次历练中锤炼出的智慧和谨慎。面对她的试探，奥托微笑回应道：

「确实，我心情沉重是事实，但如果要论思虑问题的多寡，那和需要从头建立帝国的陛下或宰相贝尔斯提兹相比，根本不值一提。」

奥托说着，将话头从自己转向在场的另一人——帝国宰相贝尔斯提兹。安娜塔西娅、贝尔斯提兹和奥托齐聚的会议室里，他们正在讨论：结束了『大灾』之战、接下来要投入复兴重建的佛拉基亚，与协助过帝国的众人，今后各自该如何行动。

在这样的氛围中，贝尔斯提兹面对奥托的引导，一双细如丝线的眼睛依旧掩藏着他的真实意图，淡然说道：

「如您所言，问题确实堆积如山。然而，说实话，我并不认为这是负担。」

「哦？真是令人感到可靠的话语啊，」安娜塔西娅惊讶地回应道。

「原本，我就是与『白蜘蛛』奇夏・戈尔德勾结、危及皇帝陛下地位的奸臣。事有轻重缓急，才未在『大灾』之战中被斩首。但照理说，战后我本应难逃处刑。」

「……但是，你现在还能和我们说话。这意味着你并没有被处置，是吗？」

「没错。皇帝陛下已经做出了这样的决定。虽然我也认为，如果有人不能原谅我，向我挥刀也是无可厚非的。」

贝尔斯提兹说到这里停顿了一下，奥托也能猜到他在沉默中思考些什么。那大概是贝尔斯提兹至今还能保住性命的最大原因——那是战后帝国最强的『青色雷光』所发布的宣言。

『趁着哪个跑龙套的还没犯糊涂，我先声明，放过贝尔斯提兹先生是陛下的决定，请各位遵从。要是谁敢违背，我也只好久违地表现一下陛下之剑的本色了。而且总觉得，连陛下不杀贝尔斯提兹先生这一步，也在奇夏的谋划里呢。说真的，少了贝尔斯提兹先生，往后不是会很难办吗？毕竟奇夏已经不在了。』

这番宣言一口气说下来，长得过头，却也切实让知晓贝尔斯提兹所作所为的人收住了手。

贝尔斯提兹似乎也想到了同一件事，嘴角稍稍扭曲：「真没想到，我竟会得到塞西尔斯・赛格蒙特一将的庇护。原以为，若不是『阳剑』斩首，也会是那位大人的刀刃落在我脖子上。」

「事情的发展并非如此。这是帝国的内务，局外人不便多说，不过我认为这是一个英明的决定。战时的武官和战前战后的文官都是不可替代的。」

「我也这么觉得。如果连贝尔斯提兹先生都不在了，脑力劳动就只能靠我一个人了，即便有可爱的皇后在旁支持，皇帝先生恐怕也会吃不消吧？」

「是啊。于我而言，陛下终于迎来了皇妃，实在是件喜事。——若连一件喜事也没有，陛下遭逢的悲痛就未免太多了。」

「————」

贝尔斯提兹缓缓地摇了摇头，叹息道，会议室顿时陷入了沉默。

在这沉默中，奥托不禁瞥向安娜塔西娅。她也在默默品味这种沉默，但感受显然与奥托不同。

这沉默的背后，是由于文森特经历的悲剧——他最亲近的部下以及同父异母的妹妹的死亡。对奥托和安娜塔西娅来说，这都无法忽视。

「真是个任性的小公主啊。」

安娜塔西娅轻声自语，奥托闭上了眼睛。那微弱的声音中，包含了一向稳重、从不为任何事动摇的安娜塔西娅难得的一丝破绽。

那是奥托一直以来渴望从安娜塔西娅身上看到的弱点——但是当这个期待已久的弱点终于出现时，他却没有利用它，选择了放手。

如果有人问他为什么这样做，

「因为这种机会具有不可复制性。」

这次出现的破绽，并不是那种可以在下次继续利用的便利工具。制造同样的机会是非常困难的，即使做得到，也不应该这样做。

毕竟，安娜塔西娅心里留下的缺口，远没有自己人心中那些伤口深重。

老实说，这对奥托来说也不是理想的结果。在过去的几个月里，艾米莉娅一行人与安娜塔西娅一行人的关系已变得过于亲近。

「其实你没必要故意把自己设想成反派。」

「——你是在对我说吗？」

在奥托和安娜塔西娅的对话中，突然有一个并非来自他们二人的第三者声音插了进来。奥托朝声音发出的方向看去，是安娜塔西娅的脖子上披着的狐狸围脖——装扮成狐狸围脖的精灵艾莉多娜正用黑色的眼睛注视着他。

面对此情景，奥托稍微皱了皱眉，而艾莉多娜微微眯了眯眼，

「你会认为这是说给你听的，正好证明了你心中所想的。」

「你可是看着我说的，这解释实在缺乏说服力。」

「你还真是固执啊，就像安娜一样。」艾莉多娜故作抱怨地说，她那狐狸般的脑袋被安娜塔西娅用纤细的手指轻轻按住，口中道：「别这样对奥托君。刚开始允许和谁都聊天，你就变得这么健谈了。」

「哼，别说得好像我只是依随自己欲望开口似的。虽然我承认，以我的立场来看，与过去的处境相比，现在确实舒适了不少。」艾莉多娜反驳道。

「真是的。抱歉啊，奥托君，我家的孩子老是这么缠人。」安娜塔西娅歉意地说道。奥托只是挥了挥手回应道：「没关系。」

艾莉多娜那一声，大概并非真的在关心奥托，而是有意强调自己的存在。身为最亲近安娜塔西娅的精灵，她自然也察觉到了奥托发现的那个缺口。那是为了不让他趁虚而入的牵制。她看不见奥托其实无意利用这破绽的内心，因此这份防备也是必要的。

不过——

「我并不认为自己是反派……如果说是角色的话，那只是演绎罢了。」奥托在心中想到，在这种意义上，艾莉多娜的指责完全没有击中要害。

普莉希拉的讣告连安娜塔西娅都动摇了，更令艾米莉娅阵营遭受了比那更大的冲击。可奥托的心却平静得连自己都觉得薄情。

奥托和普莉希拉也曾多次有言语交流，他也承认普莉希拉作为王选候补者是一位杰出的人物。然而，奥托认为：

「在王选进行的过程中，候选者缺席是完全可能发生的事情。」

虽然参与决定邻国存亡的战斗并因此丧命的情况是出乎意料的，但即便如此，当涉及到国家重大事件的政争时，暗杀者对王选候补者的生命的威胁始终存在，他们被刺杀的可能性也是很高的。

艾米莉娅阵营倒是碰上了另一种意外：派出暗杀者的，竟是自己人。即便撇开这样的例外，上述危险也依然存在。

面对这种情况，我不认为露格尼卡王国当前负责政治的『贤人会』毫无对策。

如果王选候补者因故缺席，是会有新人填补空缺，还是在五个席位中缺少一个席位的情况下继续进行王选，这都是需要考虑的问题。

后者的可能性更大，而且奥托也更希望是后者，这才是他的真心话。

正因为关系到王国的重大事件——

「在几天之内，我们将按计划回到王国。对帝国来说，他们也不希望在『大灾』之后的内部情况被其他国家的人知道更多。」

「我们也是一样。虽然步调一致听起来有点怪，但我们这边一旦准备好，明天就会出发前往卡拉拉基。奥托君，向城里报告的任务……」

「请放心交给我吧。这可是不能通过书信来沟通的事情。」

安娜塔西娅点了点头，向王城报告的职责便由奥托这一方接下。这项任务让人心情沉重，却也十分重要。奥托自然会陪同，但对艾米莉娅来说，那恐怕是个格外痛苦的差事。

此时此刻，最应该支持艾米莉娅的人是她的第一骑士。但……

「……现在的菜月昴，可能会对艾米莉娅小姐起到反效果。」

「……听你这么说，菜月君的状况还没有改善呢。」

「是的。骑士尤里乌斯已经多次来看望他，但情况依然棘手。虽然这么说有些不妥，但过去我觉得普莉希拉大人总是让他很困扰……」

「对菜月君来说，那方面并不重要。——真是危险啊。」

用平静的声音低语着，安娜塔西娅的指尖轻抚艾莉多娜的脖颈。感受到这种触感的艾莉多娜微微颤抖，黑色的眼眸中似乎也流露出对昴的担忧。

在那里，安娜塔西娅和艾莉多娜纯粹的好意显露无遗。

「王国与都市国家两位特使的意见，我都已了解。皇帝陛下命我向两国尽礼，也允我自行判断。若有所需……」

「可别说得那么轻巧。一张空白的承兑票据，最叫人心里发紧啦。」

贝尔斯提兹隐藏在细眯的眼睛后的情绪让安娜塔西娅苦笑了一下。奥托虽然与她有同样的心情，但他希望能充分利用这些话语。

这正是奥托的职责所在。他所承担的，不是艾米莉娅阵营的反派角色，而是那份『必要之恶』。

正因为如此，就算普莉希拉没有死，自己也考虑过以她是帝国皇族的身份为由，阻止她作为王选候补者，这个方法可以选择，也可以实施。

对，自己是可以选择的。

所以——，

「——即便你没有死，也未必会成为我们的敌人。可菜月先生和艾米莉娅大人因此受了伤，所以你的死……于我也是损失。」

作为不同阵营的人，奥托・苏文对那位去世的女性不应该有任何哀痛和悲伤的理由，但即使如此，这也是他所能给予的最起码的悼念。
