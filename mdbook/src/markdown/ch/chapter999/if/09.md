# 『菜月・利格尔』

------

「今年也要庆祝雷姆的生日和节分!来，尽全力的帮忙、来过这美好的日子吧!」

迎来二月二日（按昴故乡的日期换算）的菜月家，已经开始酝酿一场骚动。

每逢这种时候，率先挑起事端的，往往都是一家之主菜月・昴，这次也不例外。

「家族成员、想大家一起合力促成美好的日子。当然，你会帮忙吧，利格尔!」

昴竖起拇指，露出一口闪亮的牙齿，兴冲冲地提出这个主意。

面对摆好姿势的父亲，少年露出与年龄不符的老成表情，长长叹了口气。

叹气的是十岁的菜月・利格尔。他留着母亲那般美丽的蓝色短发，却继承了父亲的三白眼。

利格尔正在桌前写算术作业，抬眼瞥了一下为了等他回应、正左右踏步的昴，

「老爸又疯了……」

「一开口就说这个，太过分了吧！连『说了奇怪的话』都省了，直接判定发疯，也太离谱了！而且这次我提的主意又不奇怪，也不突然，明明满满都是爱吧！？」

「我害怕的就是因为溢出的爱太过盲目、要做出什么事都不知道啦。在这个家出生被养育了十年，就算是我也差不多也学习到了。」

利格尔冷眼冷声地说着，抬手推开凑过来的昴的额头，又接着道：「说到底——」

「老妈的生日还好，可我一听节分，脑子里就只有惨痛的回忆。撒豆子、吃紫菜卷那种怪节日，你让我期待什么啊……」

「不要说是奇祭阿。不，的确做的内容直接看的话是奇怪的事情，但是我不是有好好解释过了来源还有意义了吗。实际上因为那个的关系我们家没有发生不幸的事件真是万万岁了喔。」

「我平时可是吃了不少苦头，这些不幸怎么算？」

「那才不是不幸是日常。还有，要体认一件事的时候、光是在意事物不好的一面的家伙是不会成功的，而且还会累积压力喔」

「不要说的好像是我的错!本来都是因为老爸的关系我才会成为被害者好吗!」

利格尔吼了一声，双手撑桌站起来，指向窗外能看见的街道。

家门前的魔法路灯柱上贴了好几张传单，标题写着『节分来临！』，下面是活动通知。

除了记载着日期和活动内容以外也有偷偷加上了负责人的名字――、

「把那个怪节日扩大成全镇参与、莫名其妙的大活动的，不就是老爸吗？负责人那栏还有你的名字……我在学校被人说得要死，丢脸死了。」

「这可是我身为策划人的大展身手啊。尽管去炫耀吧，就说『我爸爸是我们家的英雄』！」

「要是活动说明里没写朝扮成鬼的我扔豆子，我说不定还真会那么说！」

把家中墙壁上也贴着的一张传单撕下，利格尔指着上面刊载的事项。

节分的习俗、目的与做法下方，列着二月三日（按昴故乡的日期换算）的活动内容。其中写明，扮鬼在全镇逃窜的代表，是『菜月・利格尔』。

「不要没有经过同意就把儿子卖了!你是鬼吗!」

「鬼是你，还有我老婆。不过不能让雷姆受这种罪，所以只好忍痛把儿子交出去了……」

「你是鬼吗!不对、是鬼阿你!」

「不要那么生气嘛。也没有那么多真的很认真的扔豆子的人、代表只虽说是你但也有其他当鬼的人喔。我也有好好的帮忙啊。」

对于完全没有道歉表情嘟起嘴的昴，利格尔因再说也没用而脱力。

其实，在活动内容正式公开前，两人已经为此争论了好几次。可利格尔每次都说不过昴，就这么一拖再拖，直到活动即将开始。

现在已经不能改动或取消。即便是硬塞给他的角色，一旦接下，还是得认真完成。——这种既有常识、又注定操心的性格，让菜月・利格尔的日子格外不好过。

不管怎么说，

「活动归活动，你就痛快接受吧。现在我要跟你谈的是另一件事。」

「......是老妈的生日，对吧？」

「没错」

听了边弹响指的昴的话，利格尔用鼻子哼了声将脸背对昴。

不知是什么孽缘，令人头疼的节分活动，偏偏与母亲菜月・雷姆的生日只差一天——先盛大庆祝母亲的生日，隔天再去见地狱，这就是已经排好的行程。

「照这样的心情，老妈的生日我也没办法快快乐乐的庆祝啦......」

「行程确实很紧，不过快乐的事接连来两天，也是幸福啊。往好处想想，积极一点。」

「......照这样的心情，老妈的生日我也没办法快快乐乐的庆祝啦」

这跟什么既视感无关。

现在的对话因为根本没有丝毫的动摇利格尔的心，所以结果没有发生变化也是当然的。

实在无法释怀，他花了好一会儿才调整过来。

「没错。今年算个重要的节点，我们结婚已经十年了。虽然没有明确的结婚纪念日，不过机会难得，想跟生日一起庆祝。所以，想办得比往常特别一点。」

「对吧？所以接下来才是重头戏。」

昴露出淘气小鬼般的笑容，像在邀他合谋坏事似的招手。利格尔撇了撇嘴，不祥的预感越发强烈。

但是，对于踌躇的利格尔、昴不断的不断的对他招手。

结果，利格尔没办法的叹气，将脸凑向昴。

「为这次结婚十年的庆祝计划，我准备了一份特别的礼物，已经订好了，万无一失。」

「……嗯、啊、OK」

「为了今天，我用了我偷偷一点一点存下来的私房钱买的。是很厉害的东西喔，听了会吓到吧――我准备了宝石。」

「――哎、宝石」

昴摆出「听了可别吓一跳」的架势，利格尔本来还提防着，可礼物居然真是正经而值得惊喜的东西，反而让他吃了两重惊。

虽说基本上昴在做事情时总是在多余的尝试下导致常招惹不必要的混乱，但由现在的样子来看这次并没有迹象。

「宝石吗……」

回想起来，母亲菜月・雷姆确实不怎么打扮自己。

这不是为了节省家用，而纯粹是她自己的性格。

撇开家人滤镜，利格尔也一直暗自为母亲美丽的容貌感到骄傲。

可她平时不爱打扮，觉得自己与首饰、华服无缘也没关系，这一点又让他有些不满。

虽然没有到清贫的程度、对装饰自己却毫不在意的母亲。

可这位母亲却毫不在意旁人眼光地深爱着父亲昴。尽管有点让人不爽，利格尔仍敢肯定，只要是昴送的礼物，她绝不会拒绝。

因此，父亲要送母亲宝石饰品的提案、利格尔是立刻赞成的。

「这个提案我觉得超棒的。什么嘛、有的时候做还是会成功的嘛、老爸。」

接着，利格尔便在意起宝石的模样了。毕竟，就连做儿子的，也不敢保证父亲的品味。

「当然、会全力冲刺的。――只是，老实说，有点不安。」

两指互抵着，昴的视线和声调都降了下来。

看着他的样子的利格尔扶着额、

「如果那么不安的话、之后再去拿宝石不就行了吗？比起生日当天没有礼物、老爸不在才会让老妈伤心。」

「那我知道。那我是知道的但是……若是这个生日礼物不在时间内赶到的话就没有意义了，我是这样想的。」

「那样的……」

只是老爸的任性而已、想这样说的利格尔将话吞了回去。

昴挠着头，笑得有些无奈，那淡淡苦笑里却藏着难以言说的感情漩涡。利格尔只是看着，都仿佛要被卷进去。

再插嘴就太不解风情了，利格尔明白这一点。

雷姆说出儿子的话，昴却像在回答再平常不过的事情。

坦荡荡的，一直没有自信的雷姆用自信满满的声音和表情说了。
